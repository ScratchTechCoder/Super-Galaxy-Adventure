# Super Galaxy Adventure 🚀

A retro-style Galaga-inspired space shooter game built with vanilla HTML5, CSS, and JavaScript.

## Features

- 🎮 Smooth player controls with arrow keys
- 🔫 Shoot enemies with the spacebar
- 👾 Progressive difficulty with increasing levels
- ⭐ Glowing neon aesthetic
- 💯 Score and lives system
- 🎯 Two types of enemies with different behaviors

## How to Play

1. Use **← Arrow Keys →** to move your ship left and right
2. Press **SPACE** to shoot
3. Destroy all enemies to advance to the next level
4. Watch out for enemy fire!
5. You have 3 lives - don't lose them all

## Game Mechanics

- **Basic Enemies** (Magenta): Standard aliens that shoot randomly
- **Strong Enemies** (Orange): Tougher enemies worth bonus points
- **Levels**: Each level spawns more enemy rows and increases difficulty
- **Score**: Earn 100 points per enemy destroyed

## Controls

- **Arrow Left/Right**: Move player ship
- **Spacebar**: Fire weapon
- **Click "Play Again"**: Restart after game over

You can also run this locally:

1. Clone the repository
   ```bash

   ```

2. Open `index.html` in your web browser

That's it! No build process or dependencies needed.
